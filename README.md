# Awesome Minimalism Aesthetics

> 极简主义 × 美学设计资源导航 | 一份给"少即是美"爱好者的指路清单

极简不是简单，是"删到只剩精髓"。这个仓库收集极简主义审美相关的网站、工具与阅读材料，覆盖页面设计、卡片设计、灵感来源与设计理念。

## 🐇 关于这个仓库

这个仓库始于一个很个人的念头：我想认真做好自己的个人站，把它做出"审美"来。

开始的时候，我只知道"想要极简"，却说不清什么是极简、什么算美。于是我去翻资料、逛画廊、看别人的站点，越看越发现：极简主义不是风格标签，而是一整套关于取舍的价值观——删掉多余，保留本质。

想通这一点后，我有了第二个念头：一定有很多人和我一样，在"想要极简却不知从哪开始"的路上。独乐乐不如众乐乐，不如把这一路挖到的宝贝都收进来，策展成一份清单。

所以这个仓库不止是资源导航，更是一个"价值观路由器"——把认同"少即是美"的人连接起来：你从这里拿走灵感，也欢迎把私藏的宝藏放回来。

如果觉得有用，欢迎 ⭐ Star / PR 补充。
